# CIRMS Frontend - React & Vite

Campus Item Recovery & Management System (CIRMS) Frontend Application.

## Technology Stack
- React 18
- Vite
- React Router 6
- Axios
- Lucide React Icons
- Modern Responsive CSS Design System

## Running Frontend
To install dependencies:
```powershell
npm.cmd install
```

To run development server:
```powershell
npm.cmd run dev
```

Application will run at `http://localhost:5173` with proxy pre-configured to `http://localhost:8080`.

To build for production:
```powershell
npm.cmd run build
```
